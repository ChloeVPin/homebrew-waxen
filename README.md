# Waxen Homebrew tap

Install Waxen, the read-only macOS app launch diagnostic tool:

```sh
brew install ChloeVPin/waxen/waxen
waxen ~/Downloads/MyApp.dmg
waxen finder install
```

Requires macOS 13 or newer and Xcode Command Line Tools. The formula builds from source. No prebuilt notarized binary is provided.

Source and documentation: https://github.com/ChloeVPin/waxen
